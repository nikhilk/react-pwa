# Project Overview

The application is a progressive web app that demonstrates a clean, minimal setup using
React, TypeScript, and Tailwind CSS — bundled entirely with Bun and no
additional framework or plugin layer.

## Features

- **Progressive web app** — installable on mobile/desktop, works offline via
  service worker, includes manifest and icons
- **Multi-page routing** — client-side navigation with persistent settings
- **Clean modern UX** — dark/light mode, locally bundled fonts, responsive layout
- **Persistent preferences** — user settings stored in localStorage across sessions

## Tech Stack

| Layer      | Tool                                                      |
|------------|-----------------------------------------------------------|
| Language   | TypeScript                                                |
| UI         | React 19                                                  |
| Styling    | Tailwind CSS v4                                           |
| Routing    | HashRouter (works in static site w/o server-side rules)   |
| Runtime    | Bun                                                       |
| Dev server | Custom Bun server + SSE reload                            |
| CSS build  | `@tailwindcss/cli`                                        |
| Bundler    | `Bun.build()`                                             |

## Design

### State Management

App state is managed via a generic store utility (`src/utils/store.ts`)
backed by `localStorage` and React's `useSyncExternalStore`. The app-specific
settings (dark mode, button action) are defined in `src/App.tsx` using
`createStore()`.
State is persisted to `localStorage` under the key `app-state`.

### Service Worker

The service worker (`public/sw.js`) is generated by the build script. It
uses a stale-while-revalidate strategy: serve from cache immediately,
then fetch from network and update the cache. On install, it pre-caches
all assets in `public/`. The cache name includes a build timestamp
(e.g. `app-20260531T111601`), so each production build automatically
invalidates the old cache.

### PWA Configuration

The manifest (`static/manifest.json`) declares the app as `standalone` with
a blue theme. Icons are provided at 192px and 512px (with a maskable
variant). The `start_url` and `scope` use relative paths (`./`) for
compatibility with subdirectory deployments like GitHub Pages.
